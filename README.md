# 🍔 Food Delivery MERN Application

A full-stack **Food Delivery Web Application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. The application allows users to browse restaurants, view menus, place food orders, and interact with a RESTful backend API.

---

## 🚀 Features

### 👤 User Features
- User registration and authentication
- Browse available restaurants
- View restaurant menus
- Place food orders
- Track order details

### 🍽️ Restaurant Features
- Restaurant management
- Menu management
- Order handling

### ⚙️ Backend Features
- RESTful API architecture
- MongoDB database integration
- Authentication system
- Data modeling using Mongoose

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Rafaykhan-Dev/food-delivery-mern.git
```

### 2. Navigate to the Project Folder

```bash
cd food-delivery-mern
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 5. Start the Backend Server

```bash
cd ../backend
npm start
```

### 6. Start the Frontend

```bash
cd ../frontend
npm start
```
